Field notes on running language models on a desktop GPU. A model's weights are loaded into video memory once, and every generated token then requires reading most of those weights again. That is why generation speed on a single user's machine usually depends more on memory bandwidth than on raw compute. Prompt processing behaves differently: the whole prompt can be pushed through the network in large batches, so it keeps the arithmetic units busy and runs many times faster per token. Quantization shrinks each weight from sixteen bits to eight, six, five or four, which reduces the bytes read per token and often raises generation speed, at some cost in accuracy. The key-value cache grows with context length and competes with the weights for the same memory. When the model no longer fits, some layers stay on the CPU, and the slower side sets the pace for every token.
