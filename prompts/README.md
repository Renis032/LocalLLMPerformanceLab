# Prompts

Fixed prompt texts used by experiments. Every run of an experiment sends the same prompt, so speeds are comparable. Results are matched across sessions by the prompt's content, not its file name.

| File | Purpose |
|---|---|
| [`field-notes.txt`](field-notes.txt) | An original, 521-token passage about running models on a desktop GPU. It's long enough to measure prompt processing, and it ends with an instruction to continue so generation has something to do |
